# Картинки карт

Кладите сюда файлы с такими именами — подхватятся автоматически, без каких-либо действий в самом приложении:

```
dust2.png
mirage.png
inferno.png
nuke.png
overpass.png
ancient.png
vertigo.png
train.png
anubis.png
cache.png
```

Требования:
- Расширение важно — именно `.png` прописано в `src/renderer/src/mapPool.ts`, поле `defaultImage`, под каждую карту отдельно.
- Любой размер подойдёт — картинка растягивается на всю карточку (`object-fit: cover`), но лучше вертикальную/квадратную, а не широкую панораму — верх и низ могут обрезаться.
- Если файла для какой-то карты нет — просто останется цветной градиент-заглушка, ничего не сломается.

Карточки с картами показываются только во время создания матча (экран драфта на странице Matches) — отдельного экрана управления картами в самом приложении нет, все картинки задаются только файлами в этой папке.
